# Журнал изменений

Все существенные изменения проекта будут фиксироваться в этом файле.

## [1.2.0] - 2026-08-09

### Добавлено

- Профили Redis Sentinel с несколькими Sentinel endpoint и именем отслеживаемого сервиса
- Sentinel AUTH/TLS, обнаружение master, политики чтения с replica и диагностика
- Docker-стенд из трех Redis и трех Sentinel для интеграционных проверок

### Изменено

- Записи направляются на текущий Sentinel master, разрешенные чтения могут идти на replica
- Топология Sentinel обновляется после отклоненной записи, ошибки чтения или SCAN
- Неоднозначные записи после сетевого обрыва автоматически не повторяются

## [1.1.0] - 2026-08-09

### Добавлено

- Стартовый выбор профиля, диагностическое окно подключения и явный Disconnect
- Динамическое число standalone DB, включая DB16 и выше
- Навигация `Tab`/`Shift+Tab` между DB, ключами и деталями
- Docker-стенд standalone с ключами разных типов для проверки производительности

### Изменено

- Ключи загружаются фоновыми отменяемыми SCAN worker, TYPE выполняется pipeline-пакетами, UI обновляется инкрементально
- Master-узлы кластера сканируются параллельно, PING при каждой выдаче соединения удален
- Основной интерфейс показывает DB только активного подключения

## [1.0.0] - 2026-03-02

### Добавлено

- Первый публичный релиз Redis Commander TUI
- Терминальный интерфейс для Redis Standalone и Redis Cluster
- Загрузка нескольких профилей подключения из обычного JSON, зашифрованного конфига и HashiCorp Vault
- Просмотр ключей, фильтрация, массовая отметка и удаление
- Диалоги добавления и редактирования для `string`, `hash`, `list`, `set`, `zset`, `bitmap` и `stream`
- Встроенная Redis-консоль с сохранением истории команд
- Поддержка TLS/SSL и Unix socket
- Аудит-лог в `redis_tui_audit.log`
- Пользовательская и разработческая документация на английском и русском языках
- Архитектурные диаграммы PlantUML на английском и русском языках
